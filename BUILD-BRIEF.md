# Website build brief

## Goal

Build a polished client-review website for Babar Shokut Electric Wear. Make washing machine and fridge repair the clear primary services, with AC repair secondary. The first release is a publicly viewable design preview on free GitHub Pages, with search indexing disabled until the business approves the production details.

## Business information

- Business: Babar Shokut Electric Wear.
- Google listing: Ac Repair Sharjah Babar Shokut Electric Wear.
- Owner: Bilal. Operating since 2012, according to the supplied brief.
- Address: Building 25, Shop 1, Al Yarmook Street 13, Al Yarmook, Sharjah, UAE.
- Coverage: Dubai, Sharjah and Ajman.
- Inspection fee: AED 50. This is not the complete repair price.
- Telephone: 055 243 4708, shown in the supplied Google Business Profile screenshot. Use +971552434708 for telephone links.
- WhatsApp draft destination: the same number, pending the owner's confirmation before a production launch.
- Google Maps: https://www.google.com/maps?cid=16162322832422038457

Use site-config.json as the editable source of these details. Do not add unverified hours, service guarantees, response times, review quotations, accreditation, manufacturer partnerships, repair prices or inspection-fee deductions. Do not display a stale screenshot rating as a live Google rating.

## Visual direction

Use an editorial layout with warm ivory backgrounds, deep navy typography, cobalt actions, and restrained pale-lime fee panels. Use locally hosted Manrope. Create generous spacing, crisp alignment, large readable headlines, soft borders, modest corner rounding, and carefully cropped appliance imagery. Keep animation subtle and respect reduced-motion preferences.

Palette: ivory #F6F3ED, navy #102337, cobalt #2357E8, lime #E3ECAA. Use illustrative appliance photography rather than suggesting the imagery shows the actual shop, owner, technicians or customer work. Do not introduce a fabricated owner portrait.

## Homepage

Use a slim city/service-history bar and simple branded header. Lead with “Everyday essentials. Working again.” and a washer/fridge hero. Include an enquiry action, services anchor and clear AED 50 inspection card. Give washing machines and fridges equal large service cards. Keep AC in a smaller supporting strip.

Follow with a three-step explanation, a local-business story, the three service areas, the actual address and Google Maps directions, two helpful article teasers, concise FAQs, a closing enquiry panel and a useful footer. On phones, include a compact fixed call/enquiry bar with sufficient content clearance.

## Blog and articles

Create an advice hub headed “A little know-how. A lot less worry.” Include appliance filters, real search, an empty-results state, a featured guide, four additional guide cards and problem shortcuts.

Publish five complete original guides covering a washer not draining, a fridge not cooling, a noisy washer, a fridge door seal and AC not cooling. Link to the researched manufacturer and public guidance. Keep checks suitable for general readers and defer model-specific procedures to the relevant manual. Do not invent publication dates or imply Bilal personally authored or reviewed the text.

## Functionality and accessibility

Use complete static HTML for every route, relative paths compatible with a GitHub project subdirectory, and progressive browser enhancements. The menu must support keyboard operation and Escape. Use a native accessible inspection dialog with labeled fields, required appliance/city choices and an optional symptom description.

The form must prepare an encoded WhatsApp draft. It must not send automatically, claim a confirmed appointment or store enquiries in a nonexistent backend. Keep telephone and directions links available without JavaScript. Use one H1 per page, meaningful alt text, visible keyboard focus, descriptive links, readable contrast and no horizontal overflow at narrow phone widths.

## Delivery

Include title/description/canonical/social metadata, factual structured data, sitemap, robots.txt, privacy note and a useful 404 page. Keep preview pages noindex while allowing crawlers to read that directive. Do not claim rankings or rich-result eligibility.

Build using Python's standard library and deploy only dist/ through GitHub Actions. Include source, original content, asset provenance, the font license, build instructions and a meaningful release check. Verify desktop and mobile pages, search/filter/reset behavior, menu controls, form validation, internal links, assets, contact destinations and metadata before publishing.
